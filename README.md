# 🚀 RAG from Scratch

Build and understand **Retrieval-Augmented Generation (RAG)** from the ground up.

This repository is a practical implementation of the RAG pipeline, demonstrating how Large Language Models can retrieve relevant context from external knowledge sources before generating responses. The goal is to provide a clear, hands-on understanding of the concepts that power modern AI applications such as chatbots, knowledge assistants, and document Q&A systems.

---

## ✨ What is RAG?

Retrieval-Augmented Generation combines two powerful capabilities:

🔍 **Retrieval** — Search a knowledge base for relevant information.

🧠 **Generation** — Use the retrieved context to generate accurate and grounded responses.

By incorporating external knowledge into the generation process, RAG systems can reduce hallucinations and provide more reliable answers.

---

## 🎯 Features

* Document ingestion and preprocessing
* Intelligent text chunking
* Embedding generation
* Semantic similarity search
* Context-aware retrieval
* LLM-powered response generation
* End-to-end RAG workflow

## ⚡ Getting Started

### Clone the Repository

```bash
git clone https://github.com/shivam1612tyagi/RAG-from-Scratch.git
cd RAG-from-Scratch
```

### Create a Virtual Environment with uv

```bash
uv venv
```

Activate the environment:

**Windows**

```bash
.venv\Scripts\activate
```

**Linux / macOS**

```bash
source .venv/bin/activate
```

### Install Dependencies

```bash
uv pip install -r requirements.txt
```
